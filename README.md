## ⬇️ Télécharger Stoa

**Stoa** est mon lanceur : il installe, met à jour et ouvre toutes mes applications (Tamias, Atelier, Gonia…) depuis un seul endroit.

[![Télécharger Stoa](https://img.shields.io/badge/%E2%AC%87%EF%B8%8F_T%C3%A9l%C3%A9charger_Stoa-Windows-0078D4?style=for-the-badge&logo=windows&logoColor=white)](https://github.com/ferdinandcharly/hub-apps-releases/releases/latest)

> Sur la page, choisis **`Stoa-Setup-…-x64.exe`** (PC classique) ou **`…-arm64.exe`** (PC ARM), puis lance l'installeur.
